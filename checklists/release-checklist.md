# Release Checklist

Quarter-end release readiness checks. Every item must be ticked off before the release train leaves the station.

- [ ] Release sign-off from engineering lead and product owner
- [ ] All blocking issues closed or explicitly deferred with owner and follow-up date
- [ ] Release notes drafted and reviewed
- [ ] Customer comms (in-app notice, email blast, status page) scheduled and approved
- [ ] Metrics dashboard updated with the new release version tag
- [ ] Alerts and dashboards verified against the new deployment
- [ ] Rollback plan reviewed with the on-call release manager
- [ ] Deployment window confirmed with support and ops teams
- [ ] Post-release health check scheduled for T+24 hours
